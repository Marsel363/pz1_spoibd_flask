О проекте

Данный проект создан с использованием языка программирования Python и веб-фреймворка Flask.

Цель проекта заключается в изучении базовых принципов создания веб-приложений.

В приложении реализовано несколько независимых маршрутов и используется система HTML-шаблонов Jinja.

Технологии

  • Python 3 — язык программирования
  • Flask — веб-фреймворк
  • HTML5 — разметка страниц
  • CSS3 — стилизация и оформление
  • Jinja2 — шаблонизатор
  • Адаптивная вёрстка (Flexbox)
